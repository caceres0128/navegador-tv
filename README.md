# Navegador Alejandro

Navegador ligero para TV Samsung (Tizen), como modulo de TizenBrew.

## Control remoto
| Tecla | Accion |
|---|---|
| Flechas | Mover el cursor (mantener = mas rapido; en el borde hace scroll) |
| OK | Clic |
| Atras | Pagina anterior |
| Play/Pausa | Abrir/cerrar el menu (buscar, favoritos, zoom, escudo, saltos) |
| Adelantar/Atrasar | +/-10 s en videos |

## Funciones
- Bloqueador de anuncios tipo Brave desde el inicio de cada pagina (y dentro de los reproductores).
- Escudo contra redirecciones, ventanas emergentes y capas invisibles.
- Cursor fluido con flechas y con el touchpad del celular o un mouse.
- Modo saltos: las flechas saltan de enlace en enlace.

## Requisito
TizenBrew corregido (TizenBrew-Alejandro.wgt), porque en el oficial 2.0.5
la opcion evaluateScriptOnDocumentStart esta rota.

## Instalar
TizenBrew > Module Manager > Anadir modulo GitHub > caceres0128/navegador-tv
